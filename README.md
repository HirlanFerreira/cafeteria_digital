## Organizacao
As paginas ficarao em arquivo separados para facilitar o trabalho em conjunto.
Cada pagina tera seu css.
Deve existir um aquivo geral de css (global.css)
Onde vai ficar as configuracoes gerais:
- Fonte.
- Cor de fundo.
- Header.
- Links do menu.
Todos os arquivos css estarao salvas em uma pasta styles.
O global css deve ser importado em todas as paginas, ja os arquivos css de pagina so deve ser importado na pagina que sera utilizado.

## Contribuicao
- Na branch "main" ou "master", ninguem deve subir codigo.
- Cada um vai fazer na sua propria branch.
- A cada modificao, as alteracoes devem ser enviadas para o repositorio remoto.
- Uma pessoa fica responsavel por fazer o merge de todas as branchs, na medida que alguem finalizar sua parte pode avisar essa pessoa que fara o merge para a branch principal.
